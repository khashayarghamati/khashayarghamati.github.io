Context Pollution: How Giving an LLM a Memory Made It Worse

Khashayar Ghamati • 20 August 2026

7 min read

We had what felt like an obviously good idea: give a large language model an episodic memory. Our system reads a user's brain activity from a consumer EEG headband, describes the signal in natural language, and asks a frozen LLM to classify the user's emotional state. Surely, we reasoned, if the model could remember its previous sessions with that user — accumulate experience, consolidate it into a profile, get to know them — it would classify better over time. That is, after all, the promise implicit in every "agent memory" feature shipping right now.

Instead, accuracy collapsed. With no memory at all, the model scored 40% on a four-class task where chance is 25%. With a memory of one previous session, it dropped to 32%. With a full episodic memory and periodic consolidation — the most "continual" configuration we could build without touching the weights — it fell to 12%. Below chance. The more the model remembered, the worse it got, and the difference is statistically significant (McNemar's χ² = 9.39, p = 0.002).

We call this failure mode context pollution, and I think it matters far beyond EEG. It is a structural property of any system that feeds a model's own unverified outputs back to it as context — which describes a large fraction of the agent-memory architectures being built today.

The experiment, briefly

The full details are in our ICSR 2026 paper (with Abolfazl Zaraki, Special Session SS03), but the shape of it is simple. We took Claude Haiku 4.5, froze it in the trivial sense that we never touch its parameters, and built a four-layer system around it: raw 4-channel Muse EEG becomes spectral features, the features become a ~1,900-character natural-language description, and three specialised skills — an emotion classifier, a signal-quality analyst, and a memory consolidator — reason over that text. Per-participant memory stores each session's classification, confidence, and reasoning; every five sessions the consolidator compresses episodes into a profile.

Then we varied exactly one thing: what enters the context window.

  • Zero-shot — EEG features and neuroscientific guidelines only. No memory.
  • Single-session ICL — the previous session's classification is included.
  • Continual ICL — the consolidated profile plus recent episode history. Memory in its fullest post-training form.

Same weights, same features, same prompts apart from the memory block. On the NeuroSense dataset (30 participants, 40 music-listening sessions each), evaluated on 50 sessions across 10 participants: 40.0% → 32.0% → 12.0%.

The mechanism: a self-reinforcing error cascade

Context pollution unfolds in four steps, and once you see them you will recognise the pattern in other systems.

First, during the memory-building phase, the model classifies early sessions with no help — and, consumer-grade EEG being what it is, frequently gets them wrong. Second, those predictions are stored, along with their (erroneous) reasoning, and injected into every subsequent prompt. Third, the model anchors on this accumulated context: instead of reasoning independently from the fresh signal, it interprets new data through the lens of its prior conclusions. Fourth, nothing in the loop can tell the difference between a correct memory and a wrong one — so errors compound, session after session.

The compounding is not subtle. Under full memory, 8 of 10 participants triggered what we call locked-in prediction: the model latched onto a single emotional quadrant and repeated it for every evaluation session, regardless of the true label. The prediction distribution didn't drift — it collapsed. And the degradation scaled with memory volume: one remembered session cost 8 points of accuracy; a full history cost 28.

A frozen model treats its own past outputs with the same authority as the expert guidelines in its system prompt. It has no mechanism to doubt its memories.

"Just filter the memory" doesn't work

The obvious mitigation is selectivity: only store episodes the model was confident about. We implemented exactly that — a confidence gate that admits only episodes with self-reported confidence ≥ 0.50 into memory. The improvement was marginal to the point of irrelevance (Cohen's κ moved from −0.038 to 0.043).

The reason is a known but under-appreciated fact: LLM self-reported confidence does not track correctness on out-of-distribution tasks. Our model was frequently confidently wrong, which means a confidence gate selectively retains exactly the most damaging episodes — the wrong answers delivered with conviction. You cannot ask a model to police its own memory when the model's self-assessment is itself uncalibrated.

Memory is not learning

The deeper point is a distinction the field keeps collapsing. Continual learning updates a model's parameters against ground truth; when it works, correct patterns are physically encoded into the network, and the classic hazard — catastrophic forgetting — is at least well studied. Post-training adaptation (in-context learning, RAG, agent memory, every technique that leaves weights frozen) changes only what the model sees. It cannot encode anything; it can only re-read.

These two are routinely discussed as interchangeable routes to "a system that improves with experience". They are not. Parameter updates come with a guarantee — supervision shapes the weights — and a known failure mode, forgetting. Context accumulation comes with no guarantee and a less-discussed failure mode: pollution. Whether "seeing more" substitutes for "learning" turns entirely on one question — is the accumulated context reliable? In our other systems, where memory stores ground-truth labels or externally validated outputs — as in our novelty-detection and memory-driven activity-recognition work — accumulation genuinely helps. Here, where memory stored the model's own unverified guesses about a hard, noisy signal, accumulation was poison.

What I'd tell anyone building agent memory

  • Measure your zero-shot baseline first, and keep measuring it. Memory features ship on the assumption they help. Ours cost 28 points. If you never run the memoryless ablation, you will never know.
  • Validate before you memorise. The line between helpful and harmful memory is external verification. Store what a human confirmed, what ground truth labelled, what a downstream check passed — not raw model output.
  • Don't trust self-reported confidence as the gatekeeper. On tasks far from pre-training distribution, it selects for confident errors.
  • Expect pollution to scale with memory size. If unverified outputs enter the loop, a bigger memory is a bigger liability, not a bigger asset.
  • Watch for locked-in predictions. A collapsing output distribution over time is the clinical sign that your agent is reasoning from its memories instead of its inputs.

None of this argues against agent memory. It argues that memory without verification is not a weaker form of learning — it is a different mechanism with a different failure mode, and the failure mode is quiet, cumulative, and invisible unless you look for it. We got a clean 40%→12% collapse because EEG is unforgiving. Your domain may hide the same cascade behind softer numbers.
